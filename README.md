# 物理海洋学 · 东海近岸动力专题

一个面向东海近岸研究的交互式知识网站，内容涵盖海浪、潮汐、沿岸俘获波（CTWs）与深度学习预测。

## 在线网站

https://ma-szj.github.io/physical-oceanography-atlas/

## 内容

- 沿岸俘获波的定义、时间尺度和空间尺度
- 表面重力波、表面潮汐与沿岸俘获波的区别
- 物理海洋学专题知识框架
- 19 页 Coastal Trapped Waves 课件在线预览，以及不含内嵌旁白的轻量版下载
- 配套视频入口

网站为纯静态 HTML，GitHub Actions 会把 `dist/` 自动部署到 GitHub Pages。
