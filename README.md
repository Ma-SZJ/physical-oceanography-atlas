# 描述性物理海洋 · 课程网站

一个用于建立个人知识外脑的交互式课程网站，内容涵盖海盆地形、海水物性、温盐密度结构、海气交换、潮汐、环流和经典数据分析方法。

## 在线网站

https://ma-szj.github.io/physical-oceanography-atlas/

## 内容

- 四条学习路径组成的课程首页：知识框架、教材图解、方法实验和专题 Story
- 沿岸俘获波 Story：概念、尺度辨析、配套视频与 19 页课件组成一个完整专题
- 混合层、温盐剖面、蒸发区、温跃层及四类海气热通量的 9 个课程问答
- 8 个章节组成的交互式物理海洋学知识框架
- 教材图解：33 幅图逐图解释，覆盖海盆地形、海水物性与温盐密度结构，并提供原图查看入口
- 方法实验室：T_TIDE 潮汐调和分析与 ERSST v5 海温 EOF 分解，含程序、数据、B站学习材料和 EOF 解释短视频
- RAWGraphs 学习模块：四步进度、三组可切换海洋学示例和可下载 CSV
- 出门票：五道逐题呈现的检索练习，答案和进度仅保存在当前浏览器

网站为纯静态 HTML，GitHub Actions 会把 `dist/` 自动部署到 GitHub Pages。
