一个面向东海近岸研究的交互式知识网站，内容涵盖海浪、潮汐、沿岸俘获波（CTWs）、上层海洋结构、海气热收支与深度学习预测。

## 在线网站

https://ma-szj.github.io/physical-oceanography-atlas/

## 内容

- 沿岸俘获波的定义、时间尺度和空间尺度
- 表面重力波、表面潮汐与沿岸俘获波的区别
- 混合层、温盐剖面、蒸发区、温跃层及四类海气热通量的 9 个课程问答
- 8 个章节组成的交互式物理海洋学知识框架
